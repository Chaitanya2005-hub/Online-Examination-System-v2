# 🎓 Student Management & Online Examination System v2

A comprehensive, enterprise-grade academic governance and online examination platform engineered for educational institutions. Built with **Spring Boot 3**, **Java 21**, **Thymeleaf**, and **Neon Cloud PostgreSQL**, the system digitizes academic workflows including online proctored examinations, AI-powered question generation, dynamic QR attendance tracking, fee verification, and automated PDF document issuing.

```
                                  |

```

## 🌟 Detailed Module Workflows

### 1. 👨‍🎓 Student Portal & Proctored Examination Engine
- **Online Exam Interface**: Students can select active exams, answer multiple-choice questions (MCQs), and submit responses with a real-time countdown timer.
- **AI Anti-Cheat & 3-Strike Rule**: Monitors window blur and tab switching using DOM event listeners (`document.onvisibilitychange` and `window.onblur`). 
  - *Strike 1*: Display warning banner.
  - *Strike 2*: Display critical security alert.
  - *Strike 3*: Auto-terminate the exam, submit answered questions, and log security warning counts in the database.
- **WebCam Security Monitoring**: Captures live video stream from student device during the exam.
- **Dynamic Attendance**: Students mark attendance by typing or scanning 4-digit live security codes generated by faculty.
- **Official PDF Issuing**: Download printable PDF Admit Cards and Fee Payment Receipts generated via iText.

### 2. 👩‍🏫 Teacher Portal & AI Question Generation
- **Google Gemini AI Question Bank Generator**: Teachers input a subject topic, question count, difficulty level (`EASY`, `MEDIUM`, `HARD`), and an optional custom API key. The system calls the Google Gemini API (v1beta) with automatic model fallbacks to generate structured JSON MCQs and saves them directly to the database. Includes a built-in smart fallback generator if the API key is not configured.
- **Live WebCam Proctoring Feed**: Faculty members monitor active webcam streams and anti-cheat alerts for all participating students in real time.
- **Dynamic QR Attendance Host**: Generates auto-refreshing QR codes (refreshed every 10 seconds with a 60-second validity window) using ZXing engine.
- **Assignment & Submission Management**: Create assignments, track submission counts, inspect individual student submissions, and delete assignments.
- **Student Progress Analytics**: View per-student exam count, average score percentage, and attendance percentage with instant search filtering.

### 3. 🛡️ Admin (Author) Portal & Academic Control
- **User & Subject Directory**: Comprehensive CRUD management for students, faculty, and subject catalogs.
- **Live Proctoring Monitoring**: Real-time admin dashboard view (`/admin/live-monitoring`) for active webcam streams and anti-cheat violation logs.
- **Admit Card Management**: Control student exam eligibility with instant `RELEASED` / `BLOCKED` status switches and visual status badges.
- **Fee Management & Approvals**: Assign tuition fees, edit payment records, and execute administrative `APPROVED` or `DISAPPROVED` status verifications.
- **Notices & Exam Timetables**: Broadcast, review, and delete university-wide announcements; schedule semester exams linked to subjects and manage/delete scheduled exams.

## 🗄️ Database Entity Schema (ERD Summary)

The database schema consists of 13 interconnected entities managed by JPA:

1. **`User`**: Account credentials, ERP ID, role (`STUDENT`, `TEACHER`, `ADMIN`), department, year, section.
2. **`Subject`**: Course name, subject code (e.g. `CUTM1004`), department.
3. **`Exam`**: Exam title, subject mapping, date, start time, duration, status (`SCHEDULED`, `ONGOING`, `COMPLETED`).
4. **`Question`**: Multiple choice question text, 4 options (A, B, C, D), correct answer key.
5. **`Result`**: Score, total marks, pass/fail status, security warning violations count.
6. **`Attendance`**: Attendance record for student, date, status (`PRESENT`, `ABSENT`).
7. **`LiveCode`**: 4-digit temporary security code, creation timestamp, expiration timestamp.
8. **`AdmitCard`**: Eligibility status (`BLOCKED`, `RELEASED`) linked to student.
9. **`Fee`**: Total fee, paid amount, due amount, financial status (`PAID`, `PARTIAL`, `PENDING`), approval status (`APPROVED`, `DISAPPROVED`, `PENDING`).
10. **`Notice`**: Title, message body, author, posted timestamp.
11. **`Grievance`**: Category, issue description, resolution status (`PENDING`, `RESOLVED`).
12. **`Assignment`**: Title, description, due date, creator.
13. **`Submission`**: Student assignment text, submission timestamp.

## 🚀 Quick Start & Setup Guide

### Prerequisites
- **Java JDK**: Version 21 or higher
- **Maven**: Included via `mvnw` wrapper

### 1. Clone & Navigate
```bash
git clone https://github.com/Chaitanya2005-hub/Online-Examination-System-v2.git
cd "Online-Examination-System-v2"
```

### 2. Configure Database & AI Key (Optional)
Edit `src/main/resources/application.properties` if using custom database credentials or a Gemini API key:
```properties
spring.datasource.url=${SPRING_DATASOURCE_URL:jdbc:postgresql://ep-sparkling-bird-axklmy5h-pooler.c-4.us-east-2.aws.neon.tech/neondb?sslmode=require}
spring.datasource.username=${SPRING_DATASOURCE_USERNAME:neondb_owner}
spring.datasource.password=${SPRING_DATASOURCE_PASSWORD:npg_HCOPJnw1sKx2}

# Google Gemini API Key (Optional)
gemini.api.key=${GEMINI_API_KEY:}
```

### 3. Run Locally
```bash
# Windows
.\mvnw.cmd spring-boot:run

# Linux / macOS
./mvnw spring-boot:run
```
Open your browser at `http://localhost:8080`.

## 📦 Production Packaging & Docker Deployment

### Build Production Executable JAR
```bash
.\mvnw.cmd clean package -DskipTests
```

```bash
# Build Container Image
docker build -t student-management-v2 .

# Run Container Instance
docker run -d -p 8080:8080 --name student-management-app student-management-v2
```
